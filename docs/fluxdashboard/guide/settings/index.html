Guide

Settings

One screen for everything that isn't a dashboard: your Home Assistant connection, iCloud sync across your devices, units, media sources, automatic dashboard backups, kiosk mode, geofence zones, and where Flux automations run. Your connection and your dashboards sync over iCloud to every device on the same Apple ID — and every dashboard is snapshotted automatically, so nothing is ever lost.

Two things sync, automatically Your Home Assistant connection and all your dashboards ride iCloud between devices signed into the same Apple ID. Set Flux up once; your other iPhone, iPad, and Apple TV catch up on their own. On top of that, every dashboard is backed up locally on each launch and after every edit, and any of those snapshots can be restored.

Home Assistant

The top section shows your live connection. The connection is always configurable here (and in onboarding) — it's never hard-coded.

FieldWhat it shows
StatusConnected, Connecting…, Authenticating…, Disconnected, or the failure message — with a colored icon (green / orange / red).
ServerThe base URL Flux is using (truncated in the middle when long). Works on your local network or over Home Assistant Cloud / Nabu Casa.
NameYour Home Assistant location name, as reported by the server.
HA VersionThe Home Assistant version your server is running.

Below that are the connection actions:

ActionWhat it does
ReconnectRestarts the connection with your saved server and token.
DisconnectSigns out but keeps your saved token (hidden) so you can reconnect instantly.
Forget This Server & TokenRemoves the server and token from the Keychain entirely. Use this to switch to a different server.
Local or remote, same setup Flux works locally and over Home Assistant Cloud (Nabu Casa). Disconnect is reversible; Forget is the clean slate.

Units

A single picker controls how Flux displays temperatures, distances, speeds, mass, volume, pressure, area, precipitation, and flow throughout your dashboards.

ChoiceWhat it does
Match Home AssistantLeaves every value exactly as your server sends it — no conversion.
Metric (SI)Converts values to SI units for display (°C, km, m/s, kg, L, …).
Imperial (US)Converts values to US/Imperial units for display (°F, mi, mph, lb, gal, …).
Display only The conversion changes what you see, not what's stored in Home Assistant. Values already in the chosen system pass through unchanged.

Media

Three ways to find and play media. See the Media Sources guide for the full picture of where each one plays.

SourceWhat it does
Browse Home Assistant MediaOpens your Home Assistant media library to browse and pick items.
Network Storage (NAS)Add an SMB file server on your network and browse it directly.
PlexSign in to Plex and play from your libraries.
Where it plays Home Assistant and Plex items play on your selected speakers; NAS files play locally on the device you're holding. The Media Sources page explains the split.

Sync (iCloud)

Flux uses iCloud (CloudKit) to keep your dashboards and connection in step across devices. This section makes that visible instead of leaving it a mystery.

FieldWhat it shows / does
iCloud SyncA live status label: Active, Checking…, On — restart Flux to start syncing, Off — not signed into iCloud, Unavailable — iCloud restricted, Unavailable in this build, or Off — disabled on this device. The icon is green when healthy, orange otherwise.
Sync this deviceToggle this device in or out of sync. Changes take effect the next time Flux launches.
Last sentWhen this device last exported changes to iCloud (or "Nothing yet").
Last receivedWhen this device last imported changes from iCloud (or "Nothing yet").
Sync errorShown only while a failure is actually current — it clears itself once a later sync succeeds, so a recovered hiccup doesn't linger as "still broken".
Devices merge, never overwrite Devices merge their dashboards by identity — they never overwrite each other. Turning "Sync this device" off only stops this device from syncing; it never changes which dashboards exist or where they're visible. (The store unbinds at the next launch.)
Needs iCloud If you're signed out of iCloud, sign in via the system Settings app and relaunch Flux. If a build was signed without iCloud capability, dashboards stay local — but Wi-Fi / QR sync still works.

Hidden Dashboards

This section appears only when one or more dashboards are scoped to a single device, so they don't show here. Each one lists with a tap to make it available on all your devices again. The dashboards still exist — this just brings a device-only dashboard back into the shared set, so no dashboard is ever unreachable.

Safety — Dashboard Backups

Opens Dashboard Backups, where Flux's automatic snapshots live. Flux writes a snapshot of all dashboards at every launch and after every edit session — you never have to remember to back up.

In the backups screenWhat it does
Recover Lost DashboardsIf a dashboard was on this device but isn't anymore, it's listed here with its page and widget counts. Tap Recover to bring it back as a fresh, fully-synced dashboard.
Snapshot listEach snapshot shows its date, the dashboards it contains, and the dashboard / widget counts. Tap one to restore it.
RestoreThe backup's dashboards are added back as new dashboards — nothing currently in the app is touched or replaced. Restored dashboards sync to your other devices automatically.
Additive, never destructive Restoring and recovering only ever add dashboards. Your current dashboards are left exactly as they are.

Display — Kiosk Mode

Opens Kiosk Mode: keep a wall-mounted iPad or iPhone awake, with a clock screensaver and wake-on-motion via the front camera. Full details are in the Kiosk Mode guide; in short, the screen below covers:

SettingWhat it does
Kiosk ModeKeeps the screen awake while Flux is open. The screensaver only runs in the full-screen wall panel after the idle timeout — never over your normal dashboard; any touch brings it back.
Exit button cornerWhich corner holds the subtle exit button in the wall panel (press and hold one second to leave).
Require Face ID / passcode to exitAlso asks for Face ID, Touch ID, or your passcode before leaving the wall panel.
Start afterIdle timeout before the screensaver begins (1, 2, 5, 10, or 30 minutes).
StyleFlux logo, Aurora, Digital clock, Analog clock, Dimmed dashboard, or Black screen. Clock styles add Show date and 24-hour time; the dimmed style adds a Dim amount slider.
Wake on motion (front camera)Uses the front camera to wake the panel when someone approaches, with an adjustable sensitivity.
For a complete lock To also block the home swipe, turn on iOS Guided Access (triple-click the side button while in Flux). The in-app kiosk keeps the panel awake and tidy; Guided Access is the true lockdown.

Location — Geofence Zones

Opens a full-screen, pannable map. Tap anywhere to drop a zone circle; tap a pin to select it. A floating card names the zone, sizes its radius (in meters, or feet / miles in imperial — your choice), and deletes it. These zones (Home, Work, the dock…) then appear as one-tap choices in every automation Location trigger, so automations can run when this iPhone or iPad enters or leaves a zone.

Flux Automations

A single toggle: Run automations on this device. Automations that include Apple Home devices run in Flux on whichever device has this enabled.

Don't run them twice Apple TV defaults to on (it's always awake), so this toggle is blocked on other devices while a paired Apple TV is the runner — otherwise every automation would fire twice. To run them on a handheld instead, turn automations off on the Apple TV first. Enable it elsewhere only if you don't have an Apple TV.
